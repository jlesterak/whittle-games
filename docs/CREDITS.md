# Credits

Whittle uses no third-party code, fonts, images or sounds. Art is drawn in code (Canvas 2D and inline SVG) and
sounds are synthesised with WebAudio at run time.

When something is copied or ported from another project, list it here with its URL, license and the files that
use it (see CLAUDE.md, "Original work only").

## Game rules

The US Copyright Office: "The idea for a game is not protected by copyright. The name or title given to the game
and the methods for playing it are not protected by copyright." The rules text and the art can be
(https://www.copyright.gov/register/tx-games.html, checked 2026-10-14). So classic rules are free to use, but
names, art, rules text and level layouts are always our own, and each game's doc cites where its rules come from.
